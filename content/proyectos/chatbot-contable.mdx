## Qué es

Prototipo de chatbot contable que responde consultas en lenguaje natural sobre un libro mayor de ejemplo. El backend en Python interpreta la pregunta, consulta los datos y devuelve una respuesta. También incluye carga y diagnóstico ETL, dashboard interactivo, detección de anomalías y predicción de tendencia.

## Stack

FastAPI, Pandas, procesamiento de lenguaje natural, scikit-learn y Chart.js. El README advierte que los datos son ficticios y que se trata de un prototipo, no de un sistema contable real.

## Estado

Publicado como demo en Render. No se presentan resultados contables reales.
