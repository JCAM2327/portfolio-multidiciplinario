## Qué es

Prototipo de chatbot contable que responde consultas en lenguaje natural sobre un libro mayor de ejemplo. El backend en Python interpreta la pregunta, consulta los datos y devuelve una respuesta.

## Stack

FastAPI, Pandas y procesamiento de lenguaje natural. El README advierte que los datos son ficticios y que se trata de un prototipo, no de un sistema contable real.

## Estado

Publicado como demo en Render. No se presentan resultados contables reales.
