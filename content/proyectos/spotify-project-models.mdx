## Qué es

Proyecto de análisis y modelado sobre características musicales de Spotify. El README explica que el objetivo es predecir la intensidad de una canción y entender qué variables influyen.

## Stack

Python, Pandas, machine learning y notebooks de Jupyter.

## Estado
