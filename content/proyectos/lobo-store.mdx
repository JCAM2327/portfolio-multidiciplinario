## Qué es

Página web creada para el emprendimiento LOBO STORE. Incluye una portada, presentación de productos y un flujo de contacto por WhatsApp.

## Stack

HTML, CSS y JavaScript, sin framework. El proyecto está pensado para abrirse directamente en el navegador o servirse con Live Server.

## Estado

Prototipo frontend. El repositorio no declara una demo publicada.
