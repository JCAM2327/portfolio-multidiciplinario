## Qué es

Aplicación web para agregar participantes y realizar un sorteo de amigo secreto. El sorteo evita que una persona se asigne a sí misma y la interfaz está alineada con el sistema visual del portfolio.

## Estado

Publicado como demo en GitHub Pages. Proyecto de formación, sin backend ni persistencia de datos. Los resultados se muestran en pantalla para compartirlos.
